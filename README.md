# Pweb 🚀

**Descripción**  
pWEB es un proyecto de práctica desarrollado para aprender y demostrar habilidades en **Angular** (front-end) y **Java** (back-end).  
El objetivo principal es construir una web moderna, escalable y con un diseño atractivo que simule una aplicación profesional.  
Durante este proyecto, he aprendido a manejar **componentes en Angular** y a **conectar correctamente el front-end con el back-end en Java**, mejorando así la integración entre ambas capas.
> ⚠️ **Actualmente en construcción**. Se planea añadir más efectos modernos y espectaculares para mejorar la experiencia visual.

## Funcionalidades 🛠️

- Interfaz responsiva con diseño moderno y limpio.  
- Separación clara entre front-end y back-end para practicar arquitectura escalable.  
- Manejo de **componentes en Angular** para crear interfaces reutilizables.  
- Conexión con el back-end en Java para manejar lógica de negocio y servicios.  
- Preparación para futuros endpoints y funcionalidades más complejas.
